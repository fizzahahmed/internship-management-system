# Internship Management System

A full-stack web application developed as a 4th semester university project to simplify the internship management process for students, employers, and coordinators.

## Features

- User Authentication (JWT)
- Role-Based Access Control
- Internship Listings
- Internship Applications
- Student Dashboard
- Employer Dashboard
- Coordinator Dashboard
- Progress Tracking
- Viva Evaluation
- Credit Verification
- File Uploads using Supabase Storage

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- PostgreSQL

### Storage
- Supabase Storage
